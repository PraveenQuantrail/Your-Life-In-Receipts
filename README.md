# Your-Life-In-Receipts
Your digital life is made up of hundreds of tiny moments.  A song you played at 2 AM. A place you visited. A photo you took. Something you bought. A movie you watched. A message you saved. A search you made. A random note you wrote.  Individually, these moments may not mean much.  But when you put them together, they tell a story. 

# Project Name

A modern, responsive web application built with **React**, **Vite**, and **Tailwind CSS**, featuring fluid animations with **Framer Motion**, sleek iconography, dynamic skeleton loading states, and non-blocking notifications.

---

## Features

- **Blazing Fast Bundling:** Powered by Vite for instant Hot Module Replacement (HMR).
- **Modern Styling:** Clean, utility-first styling with Tailwind CSS.
- **Fluid Animations:** Smooth layout transitions and interactive UI elements via Framer Motion (`framer-motion`).
- **Skeleton Loaders:** Enhanced perceived performance during data fetching using `react-loading-skeleton`.
- **Iconography:** Rich, customizable SVG icons via `react-icons`.
- **Notifications:** Responsive, customizable toast alerts via `react-toastify`.
